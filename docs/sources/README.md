# Reference copies

These files are the product sources this handbook was written from. The handbook in `docs/` is the build contract. If a handbook sentence conflicts with `yuklago-spec-v3.md`, the spec wins. If the screen hand-off conflicts with the spec, the spec wins. Polish notes in `figma-review-v1.0.md` do not override the spec.

The visual design is the Figma file, view only: https://www.figma.com/design/MJCyZ6SiNj6HdesKbwxDcM/YuklaGo-%E2%80%94-Product-UI-v1.0

Screens are identified by screen ID, exact UI copy, states and behaviour. Generation briefs are not part of this repository.
