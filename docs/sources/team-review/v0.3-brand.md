# YuklaGo web UI v0.3 — brand audit

**Audited:** `/workspace/hackathon/design-v0.3/yuklago-web-ui-v0.3.pdf` (32 pages) + `design-rationale.md`
**Against:** final brand spec `/workspace/yuklago-brand/final/` (Direction B "Varaq", brand-tokens v1.0, brand-guidelines.md)
**Date:** 2026-11-18 (Asia/Tashkent, UTC+5) · Reviewer: Brand designer
**Evidence:** `team-review/v0.3-brand-evidence/` (`e*` = issue, `g*` = done right)

## Verdict: **PASS WITH FIXES**

The brand is applied correctly where it counts: the real final logo files, indigo #2E2BA0 primary, Onest with a correct tight ʻ, saffron only on ink, and a consistent MASHQ banner. There are **0 blockers, 1 major and 13 minor** issues. The major issue is money amounts that wrap mid-number in narrow table columns. Everything else is polish and token consistency, and none of it is a reason to hold the demo.

## Method
- I rendered all 32 pages at native resolution (wide boards are 3× and letter pages 2× of a 1440 CSS px layout). I read each one and zoomed in on every header, logo, button, banner and amount column.
- I measured logos in CSS px (device px ÷ scale) and compared them with `final/logo/png/*`.
- I sampled pixels using the median of flat areas. For text and hairlines I used the darkest pixel cores.
- **Limitation:** the PDF is raster (a JPEG per page plus an invisible "Glyphless" text layer), so `pdffonts` can't prove Onest.
  - I checked the type visually against an Onest reference render (`g06`).
  - JPEG chroma subsampling dulls thin coloured lines and text by a few points. Flat fills match tokens exactly (primary #2E2BA0 measured #2E2BA0).
- I grepped the text layer (`pdftotext`) for o/g + U+0027 / U+2018 / U+2019 / U+02BC / U+02BB.

## Checks that passed

**Logo**
- The real final files are used, and the headers use the **small lockup** (tile = sheet, larger fold, thick white Y). It matches `final/logo/png/lockup-horizontal-small-color-*` (`g01`).
- Measured sizes:
  - web header mark 28 px (p4, p6, p10–19, p26–31)
  - desktop app header 26 px (p21–24, p26)
  - phone header 24 px (p32)
  - on-dark lockup in the your-turn panel 24 px (p23, p25; `g03`)
  - window title bar and extension panel **16 px**, exactly at the small-mark minimum (p8, p21–24; `g05`)
- No full mark below 40 px. No lockup below 20 px.
- Clear space is ≥ ¼ mark height everywhere (header gaps ≥ 18 CSS px against the 7 px needed).
- The wordmark is always one word in one colour ("YuklaGo"). It is never split, recoloured, stretched or shadowed.
- No state emblem, seal, flag or flag-colour pairing anywhere.
- Board 00 shows the full specimen set (horizontal, on-dark, stacked, mark ≥ 40, small 16–32, app icon, favicon) and the correct don'ts list (`g02`).

**Colour**
- Primary buttons, selected segments and links are **#2E2BA0** exactly (p12, p13, p14, p18).
- Secondary buttons are white with an ink label.
- Destructive actions use the stop red outline.
- Input borders read ≈#84899A (cores #88898E).
- Status colours match the tokens: caution #FFF4E0, go #E6F5EE, stop red.
- Canvas reads #F6F5FA (≈ #F5F5FA).
- **Saffron:** I scanned every page for #F5B43C. It appears only on the logo fold, the board 00 swatch, the your-turn panel band and numerals on ink #14152A, and the extension panel band. There is no saffron text, icon or button on a light surface, and no white-on-saffron.
- Amber text such as "+ 6 137 600" (p15) is caution #A35C00-family, not saffron.
- **No magenta or pink pixels** on any page (automated scan, 0 hits).
- No hazard stripes. No petrol #0B5563.

**Type**
- Onest throughout (visual match to the reference render, `g04` vs `g06`). JetBrains Mono is used for codes, URLs and IDs ("8539 52 000 9", "MASHQ-000127").
- Onest figures are fixed-width (tnum on and off measure the same), so amount columns align (p14, p19).
- **oʻ / gʻ:** the text layer has 708 o/g + **U+02BB** and **zero** U+0027 / U+2018 / U+2019 / U+0060 after o/g.
- **U+02BC** (51×) appears only as tutuq belgisi or suffix apostrophe ("maʼlumot", "baʼzan", "qatʼiy", "ed2ʼda", "CMRʼda", "YuklaGoʼda"). That is acceptable.
- Visually, ʻ is tight with no wide gaps (the v0.1 "O ʻ zingiz" problem is gone).

**MASHQ banner**
- bg **#E8EBF2** (≈ #E8EBF1) and pill **#3A4355** (≈ #3A4256) on p21, p22, p23 and p26 (both states).
- UZ copy is exact: "Mashq rejimi — bu haqiqiy bojxona kabineti emas. Hech narsa bojxonaga yuborilmaydi." with "Haqiqiy rejim haqida".
- The RU variant on p9 uses "УЧЕБНЫЙ РЕЖИМ".
- The banner stays pinned on the success state (C14), and there is no magenta.
- The real-mode boards (p24, p25) correctly have no practice markers.

**Tone**
- It reads as a calm financial tool, not a government site.
- The footer states "mustaqil xizmat. Davlat organi emas" (p5).
- "Namuna · tasdiqlanmagan" chips are on every computed number.

## CEO summary (3 lines)
1. v0.3 passes the brand check with fixes. The final logo, indigo colour, Onest type, correct ʻ and the MASHQ banner are all in place, with no emblems, magenta or beige in the product screens.
2. The one real problem is money amounts breaking onto two lines in narrow tables (p10, p12). It is a one-line CSS fix and must be done before the demo.
3. The other 13 items are polish: grey info badges, a missing watermark on 2 screens, a thick saffron bar, shield icons and page splits. About half a day in total.
