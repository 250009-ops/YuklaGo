# Definition of done

## A story

- The acceptance criteria in the story are checked, and the matching `ac-*` test from `docs/testing.md` is in the branch.
- Screen IDs it touches match `docs/screens.md` for route, states, and API operation ids.
- OpenAPI and the Prisma schema match the behaviour. Clients do not depend on an undocumented field.
- Copy is in both locale files when the screen is client-facing. The copy check passes.
- Unverified rules stay labelled. No new "Rasmiy" chip without a SOURCED row.
- The pull request template is filled in. No timeline was added.
- Support and admin behaviour, if touched, has a permission test.

## Not done

- A model SDK in the repo "so the screens look smarter".
- A guessed ed2 selector.
- A fourth role, an accountant login, or a team invite.
- A fee, a deadline, or a legal conclusion that the spec marks [UNVERIFIED], shown without that label.
