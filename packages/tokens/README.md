# Varaq tokens

CSS and JSON for the product UI. Logos are in `logo/`. The same files are also under `brand/` at the repo root, next to `brand/brand-guidelines.md`.

Import `tokens.css` from the web, console, and desktop renderer. Do not invent a second palette. Saffron (`#F5B43C`) is the logo fold and the D-05 panel only.

The Figma file is view-only design reference:

https://www.figma.com/design/MJCyZ6SiNj6HdesKbwxDcM/YuklaGo-%E2%80%94-Product-UI-v1.0
